# SecCheck CI

An AI-assisted security and code-quality automation project.

## Goal

Build an automated workflow that runs basic software tests and security checks whenever code changes are submitted.

## Planned Features

* Automated Python tests
* Static security analysis using Bandit
* Dependency vulnerability checks using pip-audit
* Automated execution through GitHub Actions
* A clear report summarizing test results and security findings
* Optional AI-assisted explanations in a future version

## Scope and Limitations

This project is intended for repositories I own or am authorized to assess.

It is a learning and automation project, not a complete penetration-testing tool. Its results may contain false positives or miss vulnerabilities, and all important findings and proposed fixes require validation.
